# wowaddons
Code for my old WoW addons that are available on CurseForge.

Most of these were last updated for Legion at the latest, so they likely don't work.

* [AtlasLoot_Classes](AtlasLoot_Classes/) - addon for AtlasLoot which would show you all racial/class/spec/talent/Artifact spells
* [BloodTrader](AtlasLoot_Classes/) - allow multi-stack buying of caches with Legion currencies, and show total amount in the vendor currency bar
* [DispelBorder](DispelBorder) - show the Mage "Spellstealable" border to buffs on target/focus that you can dispel (built into the game since Cataclysm)
* [HandyNotes_EagleFlightNetwork](HandyNotes_EagleFlightNetwork) - addon for HandyNotes that adds Hunter class hall flight path locations to the map
* [LinkFix](LinkFix) - fixes Garrison Follower (Warlords of Draenor) links to show the proper name/color
* [PetOverlay](PetOverlay) - allow macros to show pet spells including glowing autocast borders
* [ShiftReagentBank](ShiftReagentBank) - hold shift when talking to a banker to directly open up the reagent bank
* [StableHelper](StableHelper) - show pet spec/raid buff/utility in tooltips of Stable and Call Pet # tooltips
